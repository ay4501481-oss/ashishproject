# 🏦 Banking Management System

A beginner-friendly **C Programming Mini Project** developed as part of the BCA (Data Science) programme at Chandigarh University.

## 📌 Project Introduction

The Banking Management System is a simple console-based application developed using the C programming language. It helps manage basic banking operations such as creating accounts, depositing money, withdrawing money, checking balances, and viewing transaction history.

The project demonstrates the practical use of fundamental C programming concepts.

## 🎯 Project Objectives

- To understand structures and arrays in C.
- To manage basic bank account records.
- To perform deposit and withdrawal operations.
- To calculate and display account balances.
- To understand file handling for storing records.
- To develop problem-solving and programming skills.

## ⚙️ Features

1. **Create New Account** – Register a new bank account.
2. **View All Accounts** – Display all registered accounts.
3. **Search Account** – Find an account using its account number.
4. **Deposit Money** – Add money to an account.
5. **Withdraw Money** – Withdraw money if sufficient balance is available.
6. **Check Account Balance** – Display the current account balance.
7. **View Transaction History** – Display recorded deposits and withdrawals.
8. **Exit** – Save records and close the application.
